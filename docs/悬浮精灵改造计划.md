# 悬浮窗精灵化改造计划

## 1. 背景与已确认决策

在现有悬浮窗（卡片式）基础上增加**悬浮精灵**样式：以代码绘制的矢量小精灵常驻桌面，替代信息卡片。本计划对[开发执行计划](./开发执行计划.md)已交付的悬浮窗做增量改造，不改变提醒、数据与导入导出等既有行为。

已确认的决策：

- **资产路线选方案 B**：精灵完全由 WPF 矢量（Shapes/Path/Geometry）代码绘制，不引入图片序列、GIF 库或 Lottie 依赖；后续如需更精致表现，可平滑升级为图片帧序列（窗口层与设置层不变）。
- **两种样式共存可切换**：设置页提供"悬浮窗样式：卡片 / 精灵"，默认保持卡片，用户主动开启精灵。
- **精灵与品牌图标同一视觉语言**：白色圆角文档身体 + 深蓝标题条头带 + 绿色对勾徽章，与应用图标（蓝色圆角方块中的周报文档）呼应。

## 2. 精灵形象与动画设计

### 2.1 形象（矢量绘制，尺寸约 120×140）

| 部件 | 绘制方式 | 配色 |
| --- | --- | --- |
| 身体 | 圆角矩形（`Rectangle` RadiusX/Y） | 新增主题资源 `SpriteBodyBrush`：浅色 `#F6F8FB`，深色 `#E8ECF2`（避免深色主题下纯白刺眼） |
| 头带（标题条） | 顶部圆角矩形 | `AccentBrush`（跟随系统强调色，满足"强调色跟随系统"要求） |
| 眼睛 | 两个 Ellipse + ScaleTransform（眨眼） | 固定深色 `#1F2937` |
| 嘴 | 小段弧线 Path | 固定深色 |
| 对勾徽章 | 右下角 Ellipse + 白色对勾 Path | 绿色 `#23A455`（与图标一致），平时半透明，Celebrating 状态放大点亮 |

### 2.2 动画（WPF Storyboard / DoubleAnimation，无帧素材）

| 状态 | 表现 | 参数 |
| --- | --- | --- |
| Idle 待机 | 身体上下浮动 + 随机间隔眨眼 | 浮动 ±3px / 2s 往返；眨眼 120ms，间隔随机 3–6s |
| Dragging 拖动中 | 暂停浮动，身体轻微压扁（ScaleY 0.92） | 进入即生效，结束恢复 |
| Alerted 提醒 | 小幅跳动 + 头顶弹出感叹气泡 | 跳动 3 次约 1.5s；气泡显示提醒文本，6s 自动收起或点击关闭 |
| Celebrating 保存成功 | 对勾徽章放大点亮 + 弹跳一次 | 约 2.5s 后回落 Idle（二期可选钩子） |

窗口尺寸：精灵形态约 150×190（含跳动空间），卡片形态维持 320×165。性能约束：窗口隐藏时停用全部动画计时器；待机动画频率低（眨眼为秒级随机事件），常驻耗电可忽略。

## 3. 状态机设计（纯逻辑、可测试）

新增 `FloatingSpriteStateMachine`（App 项目 Services，无 UI 依赖，注入 `TimeProvider` 与项目现有模式一致）：

- **状态**：`Idle`、`Dragging`、`Alerted`、`Celebrating`
- **输入**：`BeginDrag()`、`EndDrag()`、`Notify()`（提醒触发）、`Celebrate()`、`Dismiss()`
- **关键迁移**：任意状态可进入 Dragging；EndDrag → Idle；Notify → Alerted；Alerted 超时（8s，可注入时钟验证）→ Idle；Celebrating 超时（2.5s）→ Idle；Dismiss → Idle
- **输出**：状态变更事件，由精灵控件订阅并切换对应 Storyboard

## 4. 交互映射（精灵形态下保留全部现有功能）

| 现有功能 | 卡片形态 | 精灵形态 |
| --- | --- | --- |
| 本周周次显示 | 文本行 | 悬停气泡显示；右键菜单头部 |
| 提醒状态（`SetReminderStatus`） | 文本行 | Alerted 跳动 + 气泡文本 |
| "打开记录"按钮 | 按钮 | 双击精灵；右键菜单"打开周报" |
| "收起"按钮 | 按钮 | 右键菜单"收起精灵"（托盘菜单切换不变） |
| 拖动 | 标题栏按下 DragMove | 精灵本体按下 DragMove（同模式换触发元素） |
| 位置保存/恢复/屏幕外找回 | 不变 | 不变（窗口层逻辑与样式无关，直接复用） |

透明区命中说明：WPF 窗口为矩形，精灵边缘透明区域仍会捕获鼠标，判定区略大于精灵，可接受；像素级命中（HitTest + alpha 阈值）列为后续可选优化。

## 5. 数据格式与设置

`floating-window.json` 从 `{Left, Top}` 扩展为 `{Left, Top, Style}`：

- `Style`: `0 = 卡片`（默认），`1 = 精灵`
- 向后兼容：旧文件缺 `Style` 字段时反序列化为默认 0（record 主构造参数默认值）；读写仍走现有原子写与异常提示路径
- 样式切换即时生效：关闭并重建 FloatingWindow（位置从内存/文件保留，恢复可见性检查复用现有逻辑）；写文件时携带当前 Left/Top，不丢失位置

设置页（MainWindow"设置"TabItem，"启动方式"与"DeepSeek"之间）新增"悬浮窗"小节：样式单选 + 一行说明（精灵形态下本周信息与提醒状态通过气泡和菜单展示）。

## 7. 实施步骤（每步可独立验证）

1. **抽取卡片**：卡片内容搬入 FloatingCard，FloatingWindow 宿主化——行为零变化基线，构建与桌面测试通过。
2. **偏好字段**：`floating-window.json` 增加 Style（默认卡片）+ 读写与单测——此时两种样式值都渲染卡片。
3. **精灵绘制与待机动画**：FloatingSprite 矢量形象 + Idle 浮动/眨眼；手动临时启用可见效果。
4. **交互接入**：拖动、双击打开、右键菜单、按样式调整窗口尺寸；Style=1 时完整可用。
5. **提醒联动**：气泡 Popup + Alerted 状态接入 `SetReminderStatus` 分发链。
6. **设置切换 UI**：设置页小节 + 即时重建生效 + 重启保持。
7. **测试与验收**：新增桌面测试全绿；按第 8 节人工清单验证；更新 README。
8. **（可选二期）Celebrating**：周报保存成功事件钩子 + 徽章点亮动画。

## 8. 人工验收清单

- 设置切换卡片/精灵即时生效，重启后保持；默认仍为卡片。
- 精灵可拖动、位置重启有效、显示器变更/分辨率调整后可找回（复用现有验收项）。
- 双击打开主窗口；右键菜单含"打开周报/收起"；托盘"显示或隐藏悬浮窗"对精灵同样生效。
- 触发提醒（或"测试提醒"推送）时精灵跳动并弹气泡，文本完整，6 秒自动收起。
- 浅色/深色/高对比度下精灵与气泡可读可见；强调色变化反映到头带。
- 隐藏后动画计时器停止（无持续 CPU 占用）；键盘用户仍可从主窗口完成全部操作。

## 9. 风险与缓解

- **键盘可达性回退**：精灵无按钮可聚焦。缓解：精灵为可选样式且默认关闭，主窗口始终是键盘完整入口；README 与本文档明示。
- **深色主题适配**：身体不用纯白，专用 `SpriteBodyBrush` 双主题资源；气泡沿用 `SurfaceBrush`/`MutedBrush`。
- **计划文档一致性**：开发任务计划 §4.1 要求悬浮窗展示当前周、添加记录入口、打开周报与提醒状态——精灵形态通过气泡与菜单等价满足，语义不变，不需修改原计划结论。
- **升级到图片帧序列的预留**：精灵控件对外只暴露状态机接口与内容宿主位，替换内容源不影响窗口层与设置层。

## 10. 工作量估计

方案 B（矢量绘制）：步骤 1–7 约一天；含可选 Celebrating 钩子与完整验收约 1–1.5 天。无外部资产依赖，无新 NuGet 包。
