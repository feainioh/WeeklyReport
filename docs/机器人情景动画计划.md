# 机器人闲时情景动画计划

## 1. 概述

为悬浮机器人精灵增加四个情景化闲时动画，每个包含专属道具、多阶段肢体编排与配套气泡文字，让精灵在空闲时更有"生活感"。这些动画与现有的舞蹈/东张西望/戳一戳/挥手等共享 `SpriteActionPriority.Automatic/Ambient` 调度框架。

| 动画 | 道具 | 时长 | 气泡文字 |
| --- | --- | --- | --- |
| 开门出去玩 | 小门（Canvas） | ~4.0s | "出去玩一圈～" → "回来啦！" |
| 坐车回来 | 小车（Canvas） | ~4.0s | "坐车回来啦～ ٩(๑•̀ω•́๑)۶" |
| 螺旋起飞 | 无新道具 | ~5.0s | "起飞喽～" → "着陆成功！" |
| 拿本子写笔记 | 小本子（Canvas） | ~5.0s | "让我记一下..." → "记好了！✓" |

## 2. 技术基础

### 2.1 现有动画基础设施（零改动复用）

| 组件 | 位置 | 作用 |
| --- | --- | --- |
| `SpriteActionPriority` | Services/SpriteActionPriority.cs | 5 级优先级（State > User > Celebration > Automatic > Ambient） |
| `StartBodyAction(storyboardKey, ...)` | FloatingSprite.xaml.cs | 统一入口：启动 Storyboard + 优先级互斥 + 完成回调 |
| `TryPlayAmbientAction(...)` | FloatingSprite.xaml.cs | 冷却+条件判断后调度 Ambient 级动画 |

## 3. 动画详细设计

### 3.1 开门出去玩（GoOutStoryboard）

**总时长 4.0s** | 优先级 `Automatic` | 冷却 8 分钟

| 阶段 | 时间 | 身体 | 手臂 | 道具（门） | 阴影 |
| --- | --- | --- | --- | --- | --- |
| 走向右侧 | 0.0-0.8s | TranslateX 0→15 + Y 微弹 ±3px | 自然摆动 ±8° | Opacity 0→1（淡入） | 跟随 X 偏移 |
| 开门 | 0.8-1.3s | 身体右倾 5° | 右臂前伸（-60°） | Rotate 0→75°（门打开） | 正常 |
| 走入门内 | 1.3-2.2s | TranslateX 15→30 + **Opacity 1→0** | 收回 | 保持 75° | Opacity 0.16→0 |
| 门关闭 | 2.2-2.6s | （不可见） | （不可见） | Rotate 75°→0° | Opacity 0 |
| 短暂停留 | 2.6-3.0s | （不可见） | （不可见） | 保持关闭 | Opacity 0 |
| 从左侧回来 | 3.0-4.0s | TranslateX -20→0 + **Opacity 0→1** | 挥手 | Opacity 1→0（淡出） | Opacity 0→0.16 |

**气泡**：0.0s "出去玩一圈～"（3s 显示）；3.2s "回来啦！"（2s 显示）

**Storyboard 关键动画**：
- `BodyTranslate.X`：0→15→30（出门）→ [不可见] → -20→0（回来）
- `BodyTranslate.Y`：走路时微弹（±3px，4 次循环）
- `BodyOpacity`（新增动画目标：CharacterRoot.Opacity）：1→0→0→1
- `DoorProp.Opacity`：0→1（淡入）→0（淡出）
- `DoorRotate.Angle`：0→75→0

### 3.2 坐车回来（CarReturnStoryboard）

**总时长 4.0s** | 优先级 `Automatic` | 冷却 8 分钟

| 阶段 | 时间 | 车辆 | 机器人 | 车轮 |
| --- | --- | --- | --- | --- |
| 车驶入 | 0.0-1.5s | CarTranslate.X：-45→10 + Opacity 0→1 | 站在车上（Y=-6，身体微缩0.92） | 旋转 0→720° |
| 刹车 | 1.5-1.8s | 车身微前倾（rotate 3°→0）+ 弹跳（Y 0→2→0） | 身体跟着弹跳 | 减速→停 |
| 跳下车 | 1.8-2.3s | 车保持不动 | Y：-6→0（落地）+ X：10→18（跳到右侧）+ ScaleY 压扁0.88 | 停止 |
| 车驶走 | 2.3-3.5s | CarTranslate.X：10→50 + Opacity 1→0 | 站定目送 | 旋转加速 0→540° |
| 整理 | 3.5-4.0s | （已消失） | 身体微弹（ScaleY 0.96→1）+ 天线摆动 | — |

**气泡**：1.8s "坐车回来啦～ ٩(๑•̀ω•́๑)۶"（3s 显示）

**Storyboard 关键动画**：
- `CarTranslate.X`：-45→10→10→50（驶入→停→驶走）
- `CarTranslate.Y`：0→2→0（刹车弹跳）
- `CarProp.Opacity`：0→1→1→0
- `BodyTranslate.X`：10→18（跳下车）
- `BodyTranslate.Y`：-6→0（落地）
- `BodyScale.ScaleY`：0.92→0.88→1（车上压缩→落地→恢复）
- `FrontWheel.RenderTransform.Angle` / `RearWheel...`：0→720→0→540（需要给轮子加 RotateTransform）

### 3.3 螺旋起飞（SpiralTakeoffStoryboard）

**总时长 5.0s** | 优先级 `Automatic` | 冷却 10 分钟 | **无需新道具**

| 阶段 | 时间 | 旋转 | 高度 | 缩放 | 阴影 |
| --- | --- | --- | --- | --- | --- |
| 蓄力下蹲 | 0.0-0.5s | 0° | 0→+4px（下压） | ScaleY 0.80 | 变宽 |
| 起旋升空 | 0.5-1.5s | 0°→360° | +4px→-35px | ScaleY 0.80→1.10 | 缩小变淡 |
| 持续螺旋 | 1.5-2.5s | 360°→720° | -35px→-45px（最高点） | ScaleY 1.10→1.00 | **消失** |
| 悬停 | 2.5-3.0s | 缓慢 720°→760° | -45px±2px（微浮动） | 1.00 | 消失 |
| 螺旋下降 | 3.0-4.2s | 760°→1080° | -45px→0 | 1.00→0.95 | 淡入变大 |
| 着陆 | 4.2-4.6s | 1080°（归位） | 0 | 0.95→0.82→1.00 | **最宽**（冲击） |
| 恢复 | 4.6-5.0s | — | 0 | 1.00 | 恢复正常 |

**气泡**：0.5s "起飞喽～"（2s 显示）；4.4s "着陆成功！"（2s 显示）

**Storyboard 关键动画**：
- `BodyRotate.Angle`：0→360→720→760→1080（三圈螺旋）
- `BodyTranslate.Y`：+4→-35→-45→-45±2→0
- `BodyScale.ScaleY`：0.80→1.10→1.00→0.82→1.00
- `AntennaRotate.Angle`：0→-20→15→-10→5→0（天线跟随旋转的物理摆动）
- `ShadowScale.ScaleX`：1.2→0.3→0→0.5→1.3→1
- `GroundShadow.Opacity`：0.22→0.05→0→0.08→0.28→0.16
- **双臂展开**：`LeftArmRotate` 16→80→80→16（离心展开）；`RightArmRotate` -16→-80→-80→-16

### 3.4 拿本子写笔记（TakeNotesStoryboard）

**总时长 5.0s** | 优先级 `Automatic` | 冷却 6 分钟

| 阶段 | 时间 | 身体 | 手臂 | 本子 | 眼睛 |
| --- | --- | --- | --- | --- | --- |
| 思考 | 0.0-0.6s | 微左倾-3° + 下看 | 自然下垂 | Opacity 0 | 向下看 |
| 拿出本子 | 0.6-1.0s | 回正 | 左臂伸向左（35°） | Opacity 0→1 + X：-10→0（从旁边拿出） | 看本子 |
| 翻开 | 1.0-1.4s | 前倾 4° | 左臂回收到 20° | 本子微弹（Y +1→0） | 看本子 |

| 检视 | 3.5-4.0s | 回正 + 点头（rotate 0→-2→0） | 右臂停 | 保持 | 看本子 |
| 收起 | 4.0-4.5s | 回正 | 左臂收回（20°→16°） | Opacity 1→0 + X：0→-10 | 回正常 |
| 满足 | 4.5-5.0s | 微弹（ScaleY 1→1.03→1） | 自然 | 已消失 | 眨眼 |

**气泡**：0.8s "让我记一下..."（3s 显示）；4.2s "记好了！✓"（2s 显示）

**Storyboard 关键动画**：
- `NotebookProp.Opacity`：0→1→1→0
- `NotebookTranslate.X`：-10→0→0→-10
- `NotebookTranslate.Y`：0→1→0（翻开微弹）
- `LeftArmRotate.Angle`：16→35→20→20→16（拿出→翻开后保持→收起）
- `RightArmRotate.Angle`：-16→-25→[-25~-35 振荡×14]→-25→-16（写字快速微动）
- `BodyRotate.Angle`：0→-3→0→4→4→0（思考左倾→前倾写字→回正）

## 4. 调度集成

### 4.1 空闲随机池

在 `OnIdleTimerTick` 的现有空闲行为判断中，将四个新动画加入随机池：

```csharp
// [新增-情景动画] 空闲随机池：情景动画按冷却独立调度，不与基础闲聊竞争
private readonly Dictionary<string, DateTimeOffset> _scenarioCooldowns = new();
private static readonly (string StoryboardKey, TimeSpan Cooldown, string StartText, string EndText)[] ScenarioPool =
[
    ("GoOutStoryboard",        TimeSpan.FromMinutes(8),  "出去玩一圈～",         "回来啦！"),
    ("CarReturnStoryboard",    TimeSpan.FromMinutes(8),  "",                     "坐车回来啦～ ٩(๑•̀ω•́๑)۶"),
    ("SpiralTakeoffStoryboard",TimeSpan.FromMinutes(10), "起飞喽～",             "着陆成功！"),
    ("TakeNotesStoryboard",    TimeSpan.FromMinutes(6),  "让我记一下...",       "记好了！✓"),
];

private void TryPlayScenarioAnimation(DateTimeOffset now)
{
    if (_activeBodyAction is not null || !IsVisible || IsMouseOver || ReminderBubble.IsOpen)
        return;

    foreach (var scenario in ScenarioPool)
    {
        if (_scenarioCooldowns.TryGetValue(scenario.StoryboardKey, out var last)
            && now - last < scenario.Cooldown)
            continue;

        if (StartBodyAction(scenario.StoryboardKey, extendedAction: true,
                SpriteActionPriority.Automatic, automatic: true, userInitiated: false))
        {
            _scenarioCooldowns[scenario.StoryboardKey] = now;
            if (!string.IsNullOrEmpty(scenario.StartText))
                ShowBubble(scenario.StartText, null, TimeSpan.FromSeconds(3));
            // 结束文字由 Storyboard Completed 回调触发
            return;
        }
    }
}
```

### 4.2 气泡时机

部分动画需要在**中途**（非开始时）显示第二段文字。两种方案：
- **方案 A（推荐）**：在 Storyboard 的 `Completed` 回调中显示结束文字，在 `StartBodyAction` 前显示开始文字。中途文字用 `DispatcherTimer` 延迟触发。
- **方案 B**：在 Storyboard 内嵌一个透明动画作为"定时器"，在其 `Completed` 事件中触发气泡。方案 B 更精确但耦合更高。

推荐方案 A：`StartBodyAction` 的 `onCompleted` 回调显示结束文字；中途文字用 `Task.Delay` + `Dispatcher.BeginInvoke`。

## 7. 风险与边界

- **窗口裁切**：螺旋起飞 -45px 会超出 115px 窗口（身体+天线高出窗口顶部）——设计上这是"飞走"效果，视觉上可接受
- **左右空间**：开门/坐车需要在 Canvas 内水平移动 ±30px；75px 宽度刚好够用（身体 58px + 15px 余量）
- **道具渲染**：道具使用与精灵相同的主题画刷（DynamicResource），深浅色主题自动适配
- **性能**：每个动画 <5s 且使用现有 Storyboard 引擎，无帧率影响
- **与闲聊互斥**：情景动画播放期间，`_activeBodyAction` 非空会阻止其他闲聊/动作，天然互斥
