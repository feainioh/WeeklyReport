# 悬浮机器人交互与问候开发计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，按任务逐项实现本计划。步骤使用复选框（`- [ ]`）跟踪。

**Goal:** 在现有 75×95 悬浮机器人上增加科技感表情、自然交互和可配置的问候/提醒，并让周报提醒区分“已保存 / 未保存 / 未知”三种状态。

**Architecture:** 把“行为设置与文案策略”做成独立、可单测的纯逻辑；`FloatingSprite` 只负责呈现和交互；`FloatingWindow` 负责偏好持久化与消息路由；`ReminderMonitor` 把“实际发送提醒”从普通状态文本中分离出来，`App` 查询本周周报保存状态后交给精灵。

**Tech Stack:** .NET 10、WPF、CommunityToolkit.Mvvm、System.Text.Json、xUnit。

**Spec:** 本计划第 1 节（本轮已确认的设计决策）；前置实现见 [界面现代化与精灵天线状态计划](./界面现代化与精灵天线状态计划.md)。

## 1. 已确认的设计决策

1. **外观方向：** 保留蓝色 LED 面罩、天线和圆角方体轮廓，做“科技感 + 适度表情”，不卡通化、不加手脚。窗口尺寸保持 **75×95**。
2. **性格配置：** 设置页提供 **安静 / 温和（默认）/ 活泼** 三档，以及问候、闲聊、悬停反应、提醒气泡、保存庆祝、夜间免打扰等细项开关。切换档位会恢复该档位的默认开关，之后可再微调。
3. **提醒数据：** 提醒时需要感知本周周报是否已保存；查询失败或数据库未配置时显示通用提醒，不报错、不刷屏。
4. **已保存提醒：** **蓝色轻提示、不跳动、不橙色**；未保存提醒才使用橙色 Alerted + 跳动。未知状态使用通用文案。
5. **每日问候：** 每天最多一次，**跨重启记住**（持久化 `LastGreetingDate`），避免重开应用重复问候。
6. **夜间免打扰：** 22:00–08:00 不主动问候、不闲聊；提醒仍可显示。
7. **右键交互：** 增加“打个招呼”“安静 1 小时”菜单项；后者为临时静音，不写入设置。
8. **实现约束：** 不接 AI、不发网络请求、不引入第三方 UI 库、不改数据库结构、不改现有提醒调度和系统通知内容。
9. **代码修改规范：** 继续遵守“只注释不删除”；本次变更统一使用 `[旧代码-机器人交互]` / `[新增-机器人交互]` 标签。新文件在文件头写用途注释。

### 1.1 档位默认值

| 开关 | 安静 | 温和（默认） | 活泼 |
| --- | --- | --- | --- |
| 启动与时段问候 | 关 | 开 | 开 |
| 空闲闲聊 | 关 | 开 | 开 |
| 悬停眼睛跟随 | 开 | 开 | 开 |
| 提醒气泡与动画 | 开 | 开 | 开 |
| 保存成功庆祝 | 开 | 开 | 开 |
| 夜间免打扰 | 开 | 开 | 开 |
| 闲聊间隔（开关打开时） | 120 分钟 | 90 分钟 | 30 分钟 |
| 空闲小动作间隔 | 60 秒 | 35 秒 | 20 秒 |

“安静”档默认不主动说话，但悬停仍有眼神反馈，未保存提醒仍会橙色提醒；用户可手动打开问候/闲聊。

### 1.2 消息优先级与冷却

- 优先级：拖动 > 未保存提醒 > 已保存/未知提醒 > 保存庆祝 > 戳一戳 > 问候 > 闲聊。
- 同一时间只显示一个气泡；高优先级可以替换低优先级，低优先级在气泡打开时直接跳过。
- 自动消息之间至少间隔 30 秒；闲聊在用户与精灵超过 5 分钟无交互后才可能出现。

```csharp
public enum SpriteBehaviorPreset { Quiet = 0, Gentle = 1, Lively = 2 }

public sealed record SpriteBehaviorSettings
{
    public SpriteBehaviorPreset Preset { get; init; } = SpriteBehaviorPreset.Gentle;
    public bool Greetings { get; init; } = true;
    public bool Chatter { get; init; } = true;
    public bool HoverReaction { get; init; } = true;
    public bool ReminderBubble { get; init; } = true;
    public bool Celebration { get; init; } = true;
    public bool QuietHours { get; init; } = true;
    public bool GuideShown { get; init; }
    public DateOnly? LastGreetingDate { get; init; }

    public static SpriteBehaviorSettings Default { get; } = new();

    public static SpriteBehaviorSettings ForPreset(
        SpriteBehaviorPreset preset, SpriteBehaviorSettings current) =>
        (preset switch
        {
            SpriteBehaviorPreset.Quiet => new SpriteBehaviorSettings
            {
                Preset = preset,
                Greetings = false,
                Chatter = false,
                HoverReaction = true,
                ReminderBubble = true,
                Celebration = true,
                QuietHours = true
            },
            SpriteBehaviorPreset.Lively => new SpriteBehaviorSettings { Preset = preset },
            _ => new SpriteBehaviorSettings { Preset = SpriteBehaviorPreset.Gentle }
        }) with
        {
            GuideShown = current.GuideShown,
            LastGreetingDate = current.LastGreetingDate
        };
}
```

`SpriteMessageCatalog.cs` 定义 `SpriteMessageKind`、`SpriteMessage` 和静态文案工厂。文案至少包含：

- 问候：早上好 / 中午好 / 下午好 / 晚上好，附本周 `MM-dd 至 MM-dd`。
- 首次引导：“拖住我可以换位置；双击打开周报；右键可以收起我。”

- 已保存提醒：“本周周报已保存，提醒你确认一下有没有要补充的。”
- 未知提醒：“本周周报提醒：暂时无法读取保存状态，打开周报确认一下吧。”
- 庆祝：“周报保存好了，辛苦啦。”

`SpriteMessagePolicy.cs` 提供纯函数：

```csharp
public static class SpriteMessagePolicy
{
    public static bool IsQuietHours(TimeOnly localTime);
    public static TimeSpan ChatterInterval(SpriteBehaviorPreset preset);
    public static TimeSpan IdleAnimationInterval(SpriteBehaviorPreset preset);
    public static SpriteMessage? CreateStartupGreeting(
        SpriteBehaviorSettings settings, DateTimeOffset now, DateOnly weekStart);
    public static SpriteMessage CreateGreeting(DateTimeOffset now, DateOnly weekStart);
    public static SpriteMessage? CreateFirstRunGuide(
        SpriteBehaviorSettings settings, DateTimeOffset now);
    public static SpriteMessage? CreateIdleChatter(
        SpriteBehaviorSettings settings, DateTimeOffset now,
        TimeSpan sinceLastInteraction, TimeSpan sinceLastChatter, Random random);
    public static SpriteMessage? CreatePoke(
        SpriteBehaviorSettings settings, DateTimeOffset now, Random random);
    public static SpriteMessage CreateReminder(
        WeeklyReportSavedState state, DateOnly weekStart);
    public static SpriteMessage? CreateCelebration(
        SpriteBehaviorSettings settings, Random random);
}
```

规则：
- `IsQuietHours`：22:00（含）到次日 08:00（不含）。
- 策略方法读取传入 `DateTimeOffset` 的 `DateTime` / `TimeOfDay`（即其携带的本地时钟），不要用 `LocalDateTime`（会转换到运行机器时区），保证测试与运行机器时区无关。
- `CreateStartupGreeting`：`Greetings` 关闭、`QuietHours` 开启且处于夜间、`LastGreetingDate == 今天` 时返回 `null`；否则按当前本地时间选问候语。
- `CreateFirstRunGuide`：`GuideShown` 已为 true、`Greetings` 关闭，或 `QuietHours` 开启且处于夜间时返回 `null`。
- `CreateIdleChatter`：`Chatter` 关闭、夜间、`sinceLastInteraction < 5 分钟`、`sinceLastChatter < ChatterInterval(preset)` 时返回 `null`。
- `CreatePoke`：`Chatter` 关闭或夜间时返回 `null`；否则返回随机戳一戳文案。
- `CreateReminder`：`NotSaved` 带“打开周报”动作；`Saved` 无动作；`Unknown` 带“打开周报”动作。
- `CreateCelebration`：`Celebration` 关闭时返回 `null`。

```csharp
public sealed class WeeklyReportStatusProvider(
    IWeeklyReportRepository reports,
    TimeProvider timeProvider,
    ILogger<WeeklyReportStatusProvider> logger)
{
    private static readonly TimeSpan CacheDuration = TimeSpan.FromSeconds(60);
    private DateOnly? _cachedWeek;
    private WeeklyReportSavedState _cachedState;
    private DateTimeOffset _cachedAtUtc;

    public async Task<WeeklyReportSavedState> GetWeekAsync(DateOnly weekStart)
    {
        var now = timeProvider.GetUtcNow();
        if (_cachedWeek == weekStart && now - _cachedAtUtc < CacheDuration)
        {
            return _cachedState;
        }

        try
        {
            var report = await reports.FindByWeekAsync(new WeekPeriod(weekStart));
            var state = report is null ? WeeklyReportSavedState.NotSaved : WeeklyReportSavedState.Saved;
            _cachedWeek = weekStart;
            _cachedState = state;
            _cachedAtUtc = now;
            return state;
        }
        catch (Exception exception) when (exception is not OperationCanceledException
                                        && ErrorMessages.IsExpected(exception))
        {
            logger.LogWarning("Weekly report status check failed: {ErrorType}", exception.GetType().Name);
            return WeeklyReportSavedState.Unknown;
        }
    }

    public void Invalidate()
    {
        _cachedWeek = null;
    }
}
```

## 6. 风险与缓解

- **设置项过多**：用“档位 + 细项开关”分层；切换档位恢复默认，避免用户面对一堆互相矛盾的勾选。
- **问候变打扰**：夜间免打扰、每日一次、闲聊冷却、优先级和“安静 1 小时”共同兜底；默认温和档。
- **保存状态查询失败**：返回 `Unknown` 并使用通用文案；不把数据库异常暴露给用户。
- **单击/拖动/双击冲突**：拖动阈值 + 单击延迟 + 双击取消；有纯函数单测。
- **状态信息误触发提醒**：只有 `ReminderMonitor.ReminderSent` 触发精灵提醒；普通状态只更新文本。
- **偏好文件兼容**：缺 `Sprite` 字段或档位值非法时回退默认；不丢失位置和样式。
- **性能**：问候/闲聊/空闲计时器只在精灵可见时运行；动画保持短时、低频；不引入持续高帧率动画。
