# 界面现代化与精灵天线状态改造计划

## 1. 背景与目标

上一轮已完成全局控件基础样式（字体、圆角、下划线页签），但整体观感仍偏平：卡片无层次、滚动条粗糙、列表行缺乏反馈、标题区朴素。同时机器人精灵目前用右下角绿色对勾徽章表达状态，辨识度差且与"机器人"意象不符。

本计划两部分：**界面现代化第二阶段**（层次、留白、细节反馈）与**精灵天线状态系统**（用天线颜色 + 形状/动画替代绿色徽章传达状态）。

所有修改继续遵守 `code-modification-convention` skill：旧代码注释保留并打 `[旧代码-界面现代化2]` / `[新增-界面现代化2]` / `[旧代码-天线状态]` / `[新增-天线状态]` 标签。

## 2. 界面现代化（第二阶段）

### 2.1 设计方向

Fluent 2 风格三要素：**层次**（卡片轻阴影浮起 + 弱边框）、**留白**（统一 24/16/8 间距节奏）、**反馈**（行悬停、细滚动条、悬停底色）。不引入第三方 UI 库，不使用 Mica/Acrylic 特效（WPF 模拟成本高、风险大）。

### 2.2 全局资源层（App.xaml + ThemeService）

| 项 | 内容 |
| --- | --- |
| 卡片阴影 | 新增资源 `CardShadow`（DropShadowEffect：Blur 18、Depth 2、Opacity 0.10、方向 270）；卡片边框改为半透明 `CardBorderBrush`（浅色约 8% 黑、深色约 12% 白），替代现有 1px 实色 MutedBrush |
| 细滚动条 | 全局 `ScrollBar` 模板：6px 圆角细条、悬停展宽至 8px、透明轨道、移除两端箭头按钮；`ScrollViewer` 随之全局生效（现有 5+ 处 ScrollViewer 直接受益） |
| 列表行样式 | 全局 `ListBox` ItemContainerStyle：行内边距统一、悬停 `HoverBrush` 底色、选中 10% 强调色底、圆角 6 行容器、去除默认蓝色选中块；各视图现有的本地 ItemContainerStyle 改引用全局 |
| ToolTip | 圆角 6、Surface 背景、细边框、适度阴影 |
| ContextMenu / MenuItem | 圆角 8 容器、行悬停 HoverBrush（精灵右键菜单同受益） |
| ComboBox | 圆角 8 模板、悬停/焦点强调边框、下拉列表 Surface 背景（GitProjectsView 作者筛选使用） |
| 标题栏融入 | 新增 `WindowChromeHelper`：Win11 上经 DWM（`DWMWA_CAPTION_COLOR`）将标题栏着色为 `WindowBrush` 同色，Win10 自动忽略保持默认——标题栏与界面融为一体，是"现代感"性价比最高的一项 |

### 2.3 主窗口壳层（MainWindow.xaml）

- 顶部区域重构：应用图标（`app.ico` 的 Image）+ "周报" 主标题（20pt SemiBold）+ 一行 Muted 副标题；"测试提醒 / 显示或隐藏悬浮窗"按钮保持右侧，作为次要按钮（透明底 + 悬停 HoverBrush 的新样式 `SecondaryButton`）。
- 内容区外边距 24→28，卡片间距统一 16；所有卡片 `Border` 改用统一样式 `ModernCard`（CornerRadius 12、`CardBorderBrush`、`Effect=CardShadow`、Padding 20）。
- 工作记录行：底部分隔线透明度降至 0.4、行悬停反馈、行内"编辑/删除"操作按钮改为紧凑次要按钮。

### 2.4 各视图微调（WeeklyReportsView / GitProjectsView / BackupView）

- 根卡片统一 `ModernCard`；区域标题统一 20/14 两级层次（标题 SemiBold + Muted 说明行）。
- ListBox 接入全局行样式；空状态文案居中 + Muted 放大留白。
- 不改任何绑定、命令与业务逻辑，纯表现层调整。

### 2.5 明确不做

自定义无边框标题栏（WindowChrome 全自绘）——风险与收益不成比例，本期用 DWM 着色近似；CheckBox/RadioButton 自绘字形——系统默认在 Win11 下已较现代，仅保留间距与手型。

## 3. 精灵天线状态系统

### 3.1 状态 → 天线映射（替代绿色徽章）

| 状态 | 天线颜色 | 形状 / 动画 |
| --- | --- | --- |
| Idle 待机 | 强调色（跟随系统主题） | 小球缓慢呼吸（透明度/缩放 3s 周期） |
| Dragging 拖动中 | 强调色 | 天线整体前倾 15°、球缩至 0.8 |
| Alerted 提醒 | 警示橙 `#F7630C` | 球放大 1.4×、0.5s 快闪 6 次 + 扩散光环（球外圈描边圆环放大淡出）；文本仍走头顶气泡 |
| Celebrating 保存成功 | 成功绿 `#16A34A` | 球弹跳放大 + 天线杆左右摆动 3 次 |

颜色承担主语义（蓝=常驻、橙=注意、绿=完成），动画承担强度与时效；悬停气泡继续提供文字详情，保证非色彩渠道可用（满足无障碍要求）。

### 3.2 实现要点

- **移除徽章**：机器人身体右下角绿色对勾徽章整体注释保留（`[旧代码-天线状态]`），身体更清爽。
- **结构**：天线三件套命名——`AntennaGroup`（杆 + 球 + 光环，含 RotateTransform 供前倾/摆动）、`AntennaBall`（Fill 由状态驱动）、`AntennaHalo`（默认 Opacity 0，仅提醒态启用）。
- **动画**：新增 `AntennaBreathe`（待机呼吸，Forever）、`AntennaAlertBlink`（球快闪 + 光环扩散循环至状态结束）、`AntennaWiggle`（摆动 3 次自停）三个 Storyboard；状态切换在 `ApplyState` 中统一驱动（换色用 `FindResource("AccentBrush")` 保持主题跟随，橙/绿为固定语义色）。
- **状态机不变**：四态状态机与既有测试全部复用，仅呈现层换装。
- **Celebrating 接线（补上此前二期的缺口）**：`WeeklyReportsViewModel` 保存成功路径新增 `ReportSaved` 事件 → `MainWindow` 订阅 → `App.RequestFloatingCelebration()` → `FloatingWindow.Celebrate()` → 精灵态转发 `_machine.Celebrate()`（卡片态忽略）。这是天线"绿"状态唯一的真实触发源。

## 4. 测试与验收

- 自动化：单元 114 + 桌面 21 保持全绿；新增 `ReportSaved` 事件触发的 ViewModel 测试（沿用 BackupViewModelTests 的构造模式）。
- 人工验收：
  - 界面：卡片浮起有层次、深浅色均无脏边；滚动条细且悬停展宽；列表行悬停/选中反馈；标题栏与界面同色（Win11）；五个页签页视觉一致。
  - 精灵：常驻蓝球呼吸；拖动前倾；点"测试提醒"后橙球快闪 + 光环 + 气泡；保存周报后绿球摆动；徽章已消失。
  - 回归：托盘退出 0.5s 内干净退出；单实例；主题切换即时反映。

## 5. 实施顺序（每步可验证，全程 debug 运行，不打包）

1. 全局资源层：CardShadow/CardBorderBrush/HoverBrush、细滚动条、ToolTip、ContextMenu（构建 + 截屏对比）。
2. 列表行 + ComboBox 全局样式，各视图接入。
3. MainWindow 壳层重构（标题区、ModernCard、间距）+ DWM 标题栏着色。
4. 精灵：移除徽章、天线命名结构、三个新动画、ApplyState 状态驱动。
5. Celebrating 接线（VM 事件 → App → 精灵）+ 测试。
6. 整体验收：截屏视觉评审 + 退出回归 + 全量测试。
7. 完成后询问是否打包发布（含"先卸载旧版"安装逻辑验证）。

## 6. 风险与缓解

- **全局 ScrollBar/ListBox 样式波及面广**：若某视图出现布局异常，该视图可局部回退旧样式（注释保留制使回退低成本）。
- **DropShadow 性能**：仅卡片根 Border 少量元素应用（每页 ≤3 张），不套在列表行内；低配机可后续加开关。
- **DWM 标题栏着色仅 Win11 生效**：Win10 保持系统默认标题栏，属可接受的渐进增强。
- **天线 6px 级细节在小尺寸下不可辨**：颜色 + 动画双通道，且气泡/悬停提供文字兜底。

## 7. 工作量估计

全局资源层与壳层约 1 天，列表/视图接入 0.5 天，天线系统与接线 0.5 天，验证与收尾 0.5 天，合计约 2.5 天。
