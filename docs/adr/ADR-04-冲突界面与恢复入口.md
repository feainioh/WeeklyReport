# ADR-04 冲突界面与恢复入口

状态：设计方向已接受（Phase 0，2026-11-03）；交互细节在 Phase 2 实现时细化并补验收

## 决策

- **冲突处理入口**：设置页存储区块新增"冲突待处理（N）"入口 → 冲突列表页（对象、冲突原因、双方版本与基线）；操作仅三种：保留本地、保留 MySQL、编辑合并结果；确认前再次比较目标，目标已变则要求重新预览；关联事务组不产生半成功状态（任一对象无法应用则整组保持冲突）。
- **状态展示入口**：主窗口标题区常驻存储状态（已同步/待同步 N/冲突 N/连接异常/本地存储异常，多态并存）；悬浮卡片与机器人消费同一状态契约。
- **恢复入口**：完整本机备份恢复入口在设置页存储区块，恢复前预览（时间/身份/待同步/冲突数量），恢复后暂停同步直至身份校验通过（引用《备份功能离线化改造计划》§3.3）。
- **暂停/恢复同步入口**：身份不匹配、协议不兼容、数据库切换时自动暂停并在设置页给出明确恢复路径；用户可手动"立即同步"。

## 边界

- 冲突界面只做导航与确认，不自动写入；解决动作全部经用户确认。
- 本 ADR 的 UI 细节（布局/文案）不在 Phase 0 定稿；Phase 2 交付时按《界面现代化》既有样式体系实现。
