# 悬浮机器人形象与动画优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保持 75×95 窗口和既有交互契约的前提下，把悬浮机器人从“圆角药丸 + 多轨线性动画”改为可读的陶瓷小机甲，并建立短、有重量、可收势的动作系统。

**Architecture:** 静态几何重排为 58×58 外壳、48×20 面罩、外置两段手臂、腿脚锚定和柔和接触阴影；主题色集中到 `SpritePalette`。动画改为单一全身动作通道 + P0–P4 优先级 + 200ms 收势；移除全身 bob、3×13px 跳跃和 4.2 秒舞蹈，改为眨眼、天线呼吸、低频瞥视/重心移动、1.5 秒挥手、1.2 秒庆祝和 2.2 秒小踏步。

**Tech Stack:** .NET 10 / WPF / XAML Storyboards / `System.Windows.Media.Animation` / xUnit / `dotnet test`。

**Spec:** [悬浮机器人动态动画计划.md](悬浮机器人动态动画计划.md)（现状、约束与首轮实施记录）；本计划“设计决策”章节是本次变更的规格。

### 动作系统

- 90% 时间只有眨眼 + 天线呼吸；身体不常驻 bob。
- 四拍：预备 80–120ms、发力 160–260ms、过冲 60–100ms、回稳 200–320ms。
- 错峰 40–120ms：阴影 0、躯干 0、天线 +60–90、手/脚 +80–120。
- 同一时刻只允许一个全身动作；一个变换属性只有一个写入者。
- 脚底锚定 y=92；跳跃 ≤3px；落地必须有阴影变化和 1 帧停顿。
- 打断/抢占/自然结束都要收势：读当前值 → Stop/Remove → 180–220ms 归位；隐藏/卸载直接停止并复位。禁止单帧 Reset。
- 所有关键帧必须有 EasingFunction；禁止 `LinearDoubleKeyFrame` 和无 EasingFunction 的 `EasingDoubleKeyFrame`。
- 身体缩放限制在 0.96–1.03；不再用 0.86/1.12 的大幅橡皮形变。
- 第一版不引入 `FaceRig` 反向缩放：3% 的挤压不足以读成橡皮脸；如果 150% DPI 目视仍明显，再作为后续任务补反向补偿，避免为小概率问题增加整套同步动画。

### 频率与设置

- 安静：`AutoIdleActions=false`；只保留眨眼/天线呼吸；手动右键仍可用。
- 温和：瞥视 150s、重心移动 135s；**自动 TwoStep 关闭**；闲聊 90min。
- 活泼：瞥视 90s、重心移动 60s；自动 TwoStep ≥60min；闲聊 30min。
- `DynamicActions` 关闭：只保留 BasicPoke、表情、天线脉冲；Wave/TwoStep 菜单置灰。
- `AutoIdleActions` 关闭：关闭全部自动环境动作（瞥视/重心移动/自动 TwoStep）。
- 旧偏好文件字段不变；不改 JSON schema。
- 工作节律提醒使用 Alert Soft，橙色保留给“未保存周报”。

### 明确删除/降级

- 停用全身 `BobStoryboard`（-2px 永久浮动）。
- 停用 `JumpStoryboard`（3×-13px）和 `Jump.Completed → StartIdleAnimations`。
- 停用 4.2 秒 `DanceStoryboard`（10 轨同相位、线性关键帧）。
- 停用每 35 秒 `LookAroundStoryboard`（躯干 ±4°）。
- 停用 6 次 `AntennaAlertBlinkStoryboard` + 永久光环。
- 重写 `WaveStoryboard`（145° 单段风车）为两段折叠臂。
- 停用 `SquashStoryboard`/`UnsquashStoryboard` 的 0.92 大幅挤压。
- 停用 `GroundShadow.Width` 动画，改 `ShadowScale` + Opacity。
- 停用 `ChestLed` 跟随天线换色，改为固定核心。
- 旧几何、旧 Storyboard、旧代码全部按项目规范用注释保留，不得删除。

- 窗口固定 75×95；角色只由 XAML 几何图形绘制；不新增图片、外部素材、第三方动画库、网络/AI/声音。
- 旧代码只注释不删除；新代码用 `[新增-形象动画2]`，旧代码用 `[旧代码-形象动画2]`。

- 同时适配浅色、深色、高对比度；高对比度使用系统色，rim/高光/阴影可降为透明。
- 所有描边 ≥1.5px；不再出现 0.8/1.2/1.6px 细节线。
- 身体缩放限制 0.96–1.03；脚底 y=92；任何动作不得超出 75×95 可见包络。
- 保持拖动阈值、`DragMove`、单击戳一戳、双击打开、右键菜单、气泡按钮、提醒优先级、位置/偏好持久化不变。

## Review Focus

1. **挥手手臂中段越界或穿面罩**：单段臂在 90° 附近会滑出窗口；两段折叠臂的肩/肘关键帧必须逐帧检查。由 Task 4 的 `SpriteArmGeometryTests` 覆盖关键姿态边界，Task 8 再做实际窗口逐帧目视。
2. **挤压/弹跳把脸和眼睛拉变形**：身体缩放必须限制在 0.96–1.03；面罩/眼睛不得再随 0.86/1.12 大幅缩放。由 Task 2 的设计值、Task 5/6 的 Storyboard 数值和 Task 8 的视觉矩阵覆盖。
3. **打断、隐藏、卸载后残帧**：任何抢占都必须先 Stop/Remove 再收势；隐藏/卸载不得留下动画时钟。由 Task 3 的优先级测试、Task 5 的状态机测试和 Task 8 的打断矩阵覆盖。
4. **主题对比与硬编码颜色**：深色主题近白机身 + `MutedBrush` 细节只有约 1.45:1；眼睛硬编码白色在浅强调色上会消失。由 Task 1 的 `SpritePaletteTests` 覆盖对比度，Task 8 用 `rg` 检查硬编码。
5. **自动动作打扰与旧设置兼容**：自动动作必须在悬停、气泡、静音、免打扰、非 Idle 时停止；温和档不得自动 TwoStep。由 Task 4/6 的策略测试和 Task 7 的偏好测试覆盖。
